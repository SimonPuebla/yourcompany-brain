## Estados

Ajustar esta lista a los estados que use el canon de la empresa.

| Término | Significado |
| --- | --- |
| `approved` | Usable frente a terceros dentro del alcance indicado. |
| `conditional` | Usable solo con sus condiciones y disclaimer. |
| `in_progress` | Trabajo real que todavía no es oferta ni prueba. |
| `planned` | Intención futura; nunca se presenta como disponible. |
| `deprecated` | Reemplazado; se conserva por trazabilidad. |
| `blocked_unverified` | Salida obligatoria cuando falta un hecho, fuente, owner o autorización. |

## Operación del brain

| Término | Significado |
| --- | --- |
| Canon | Lo aprobado en `main` de este repositorio. |
| Candidato | Diferencia detectada entre una fuente viva y el canon, a la espera de revisión en `_inbox/`. |
| Ángulo | Dominio de revisión con un único revisor, según `governance/ciclo-semanal.md`. |
| Clase A / Clase B | Hecho fechado que no cambia lo que se promete / cambio de precio, claim, alcance, disponibilidad u owner. |
| Fuente viva | Correo, reuniones, documentos, CRM, capa de trabajo o fuente pública. Aporta evidencia, no verdad aprobada. |
| Agenda semanal | Documento de la semana donde cada revisor contesta sus cambios. |
| Copia de lectura | Página `Canon vigente` que el equipo consulta sin abrir el repositorio. |
