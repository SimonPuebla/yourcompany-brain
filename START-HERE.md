# Empezar

Si este repositorio todavía es un template vacío, empezar con `skills/company-setup/SKILL.md`.

Si el brain ya está armado:

1. Leer `AGENTS.md` y `brain.yml`.
2. Identificar el trabajo y elegir un `SKILL.md` de `skills/`.
3. Leer sólo el canon y las fuentes funcionales necesarias.
4. Si falta evidencia, owner o autorización, devolver `blocked_unverified`.
5. No modificar el canon sin una fuente, owner y fecha de revisión.
