# Empezar

Si este repositorio todavía es un template vacío, empezar con `skills/company-setup/SKILL.md`.

## Si el brain ya está armado

1. Leer `AGENTS.md` y `brain.yml`.
2. Identificar el trabajo y elegir un `SKILL.md` de `skills/`.
3. Leer sólo el canon y las fuentes funcionales necesarias.
4. Si falta evidencia, owner o autorización, devolver `blocked_unverified`.
5. No modificar el canon sin una fuente, owner y fecha de revisión.

## Si sos parte del equipo

No hace falta abrir este repositorio para el trabajo diario.

- Para usar el canon: abrir un chat conectado al repositorio y pegar `CHAT-BOOTSTRAP.md`. Cada merge te actualiza solo.
- Para leerlo: la página `Canon vigente` de la capa de trabajo.
- Para proponer o aprobar un cambio: contestar las filas donde te etiquetan en la agenda semanal.

## Si sos el owner del canon

- Revisar y mergear el PR semanal.
- Mantener completos los revisores de `governance/ciclo-semanal.md`.
- Programar el ciclo con `automation/README.md`.
