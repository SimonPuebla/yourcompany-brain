# Skills de la empresa

El mismo paquete se instala como plugin en Claude y como repositorio en Codex. Cada skill debe declarar propósito, lecturas requeridas, flujo, salida, límites y condiciones de parada.

- `company-setup`: guía el primer armado del brain desde este template vacío.
- `company-router`: rutea pedidos al canon y al skill aplicable.
- `company-discovery`: releva y califica oportunidades comerciales.
- `company-proposal`: prepara propuestas usando sólo claims y fuentes aprobadas.
