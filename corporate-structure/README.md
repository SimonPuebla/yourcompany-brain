# Estructura societaria

Esta carpeta es opcional y de uso interno. Registrar sólo fuentes controladas, nombre legal, jurisdicción y tipo societario cuando estén confirmados.

Nunca publicar titularidad beneficiaria, porcentajes, identificación personal, domicilios personales, datos bancarios ni una fuente con datos personales. Ante una pregunta externa, responder sólo lo que esté aprobado para publicación y escalar el resto al owner.
